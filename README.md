# Мир Вампуса (World of Wampus)

Логический агент-охотник в пещере N × N: измеряет сигналы датчиков, пополняет базу знаний,
делает логический вывод и выбирает ход. Постановка — по методичке «World of Wampus».

## Правила мира

* В пещере есть Вампус (W), ямы и золото. Расстановка случайная, старт охотника — левый нижний угол (N, 1).
* Вампус сторожит золото, которое лежит в соседней комнате. Взять золото можно только после того, как Вампус убит.
* У охотника одна стрела, она летит по прямой до стены.
* Около ямы — ветерок (Breeze), около Вампуса — запах (Stench), около золота и на нём — блеск (Glitter),
  при ударе о стену — Bump, при гибели Вампуса — крик (Scream).
* Поле может быть любого размера (2…20), количество ям растёт пропорционально числу комнат:
  `ям = round(N * N * pit-ratio)`.
* Очки: −1 за действие, −10 за выстрел, +1000 за золото, −1000 за гибель.

Координаты записываются как в методичке: `строка,столбец`, строка 1 — верхняя.
Охотник стартует лицом вправо.

## Как рассуждает агент

База знаний (`KnowledgeBase`) хранит посещённые комнаты и показания датчиков и после каждого
измерения заново выводит представление о каждой комнате:

| Обозначение | Смысл |
|---|---|
| `OK` | безопасно: нет ни ямы, ни живого Вампуса |
| `P?` / `P!` | может быть яма / яма точно |
| `W?` / `W!` / `Wx` | может быть Вампус / Вампус точно / убитый Вампус |
| `G?` / `G!` | может быть золото / золото точно |

Порядок решений агента (`HunterAgent`): взять золото → убить известного Вампуса → идти к золоту →
идти к ближайшей безопасной клетке → выстрелить наугад по `W?` → рискнуть, если вероятность
гибели не выше `max-risk` (вероятность ямы считается по Байесу перебором расстановок) → завершить поход.

## Запуск оконного приложения (JavaFX)

JavaFX не входит в JDK, поэтому запускать нужно через Maven-цель, которая подключает
`module-path` и нативные библиотеки текущей ОС:

```bash
mvn javafx:run
```

В IntelliJ IDEA: окно **Maven** → **Plugins** → **javafx** → `javafx:run`.
Запускать нужно `com.vadim.wampus.WampusApplication`, а не `WampusFxApplication` напрямую.

В окне:

* слева — реальная пещера в стиле рисунка из методички (галочка «показать» скрывает её,
  чтобы видеть только знания агента);
* в центре — представление агента: `OK`, `P?`, `P!`, `W?`, `W!`, `G?`, `G!`, серые клетки — посещённые;
* справа — журнал рассуждений по шагам: измерение, логический вывод, решение, действия;
* «Авто» — агент играет сам, «Ход агента» — один шаг; кнопки «Вручную» — играете вы,
  а агент показывает совет;
* вкладка «Настройки» — размер поля, доля ям, зерно, мир из методички, допустимый риск.

Горячие клавиши: `↑`/`W` — вперёд, `←`/`A` и `→`/`D` — поворот, `пробел` — выстрел, `G` — взять,
`Enter` — ход агента, `N` — новая пещера.

## Консольный режим

```bash
mvn spring-boot:run -Dspring-boot.run.arguments="--wampus.console=true"
```

Каждый шаг печатается в формате методички: `Step`, результат измерения, логический вывод,
представление агента таблицей и решение.

Параметры (`src/main/resources/application.yml`, можно переопределить из командной строки; в окне — на вкладке «Настройки»):

| Параметр | По умолчанию | Описание |
|---|---|---|
| `wampus.console` | `false` | `true` — консоль вместо окна |
| `wampus.mode` | `auto` | `auto` — играет агент, `manual` — играете вы, агент подсказывает |
| `wampus.size` | `4` | сторона поля N |
| `wampus.pit-ratio` | `0.2` | доля комнат с ямами |
| `wampus.seed` | `0` | зерно генератора, `0` — каждый раз новая пещера |
| `wampus.demo` | `false` | пещера с рисунка из методички |
| `wampus.max-risk` | `0.35` | допустимая вероятность гибели при вынужденном риске, `0` — не рисковать |
| `wampus.max-steps` | `500` | лимит шагов |
| `wampus.show-world` | `false` | показать реальную пещеру в начале игры |

Примеры:

```bash
# мир из методички — шаги совпадают с примером Step 1–3
mvn spring-boot:run -Dspring-boot.run.arguments="--wampus.console=true --wampus.demo=true"

# поле 8x8, ручной режим
mvn spring-boot:run -Dspring-boot.run.arguments="--wampus.console=true --wampus.size=8 --wampus.mode=manual"
```

Команды ручного режима: `f` — вперёд, `l` — налево, `r` — направо, `s` — выстрел, `g` — взять золото,
`Enter` — ход агента по его совету, `q` — выход.

Если в консоли Windows вместо русских букв и рамок видны «кракозябры», выполните `chcp 65001`
перед запуском.
